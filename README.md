## 使用方法
1. 安装 Python 3.11 或更新版本，在项目目录中安装依赖：
   ```sh
   python -m pip install -r requirements.txt
   ```
   依赖包括 `requests` 和 `websockets>=13.1`，后者提供扫码登录使用的异步客户端接口。
2. 在项目目录运行脚本：
   ```sh
   python ykt.py
   ```
3. 运行之后，脚本会弹出一张微信二维码，扫码登陆就行了，注意请确保你已经在微信上绑定了自己的雨课堂信息！
![示例图片](example.png "微信扫码")
4. 扫码后，脚本会打印你当前所有课程，然后选择你要观看的课程编号。
![示例图片](example1.png "课程编号选择")
5. 等待刷课结束
![示例图片](example2.png "刷课结束")
6. 自行查看成绩。如果出现“未能确认完成”，请根据提示检查并重试；进度提交成功并不代表服务器已经确认完成。

## 兼容与进度处理
- 二维码保存为脚本目录中的独立文件；该目录不可写时使用系统临时目录。终端会显示绝对路径，也可以按该路径手动打开。
- 视频详情优先从雨课堂主站查询，失败时尝试西电研究生站点；播放资源与请求头随实际视频来源切换。仍主要面向西电研究生课程，其他学校需自行验证。
- 遍历小节和章节直属的资源，同一章节中的重复资源只处理一次；非视频内容会跳过。
- 已完成的视频不再提交进度。缺少时长时从课程信息、进度信息或 HLS/MP4 元数据读取；无法取得有效时长时会报告未确认，不猜测时长。
- 进度记录查询和提交轮数有限，只有服务器确认的视频才视为完成。播放清单、播放信息接口和 MP4 元数据读取均有大小或次数限制。
